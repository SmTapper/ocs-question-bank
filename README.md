# OCS 本地 AI 题库

给 OCS 网课助手配一个「自己的题库」：**先查本地题库 → 查不到再问大模型 → 答案自动存进题库**。
下次遇到同一道题就不用再花钱调模型了。

- 不需要安装任何依赖，本机有 Node.js 就能跑
- 所有题目、配置、日志都存在本地 `data/` 目录，随时备份
- 带一个可视化后台，加题、导入题库、配模型都在网页上完成

---

## 从 GitHub 克隆后首次使用

```bash
git clone <你的仓库地址>
cd OCS网课助手
```

然后双击 **`安装桌面快捷方式.bat`**（装一次快捷方式），再双击 **`启动服务.bat`** 即可。
首次启动会自动创建 `data/` 目录和默认配置，**不需要手动复制或填写任何文件**。
之后在管理后台的「模型配置」里填 API Key、在「题库管理」里导入或添加题目。

> **隐私说明**：`data/` 整个目录都在 `.gitignore` 中，
> 题库（`questions.json`）、查询日志（`query.log.jsonl`）和含 API Key 的
> `config.json` 都**不会被提交到 GitHub**。
> 根目录的 `config.example.json` 是脱敏后的配置结构示例，仅作参考。

## 一、启动

### 推荐：桌面图标（双击即用）

第一次使用，双击 **`安装桌面快捷方式.bat`**，它会在桌面生成一个「OCS 本地 AI 题库」图标
（带自定义图标）。**只需装一次**，重装/挪动项目后再点一次即可。

之后的使用方式：

| 操作 | 结果 |
|---|---|
| 双击桌面图标 | 启动服务，并自动打开管理后台 |
| 关闭弹出的黑色窗口 | 服务立刻停止 |
| 服务已在运行时再双击 | 不重复启动，直接打开管理后台 |

窗口开着就代表服务在跑，最小化也行。**答题时别关它**，关掉 OCS 那边就查不到了。

### 也可以直接双击 `启动服务.bat`

效果完全一样，只是桌面上没有图标。

> 命令行启动：在本目录执行 `npm start`
> 换端口：`set PORT=8899 && npm start`（`启动服务.bat` 里的端口检测也要一起改）

## 二、先配模型

后台 → 左侧「模型配置」，是一个左右分栏的界面：

- **左栏**：AI 平台管理，列出已添加的平台；底部是「通用设置」
- **右栏**：选中平台的 API Key、接口地址、模型列表

### 1. 添加平台

点左栏右上角的 `+`，可以从预设里选（DeepSeek / 阿里云百炼 / 智谱 / Kimi / 硅基流动 / OpenAI / OpenRouter / 本地 Ollama），
也可以自定义名称和地址。填上 API Key，保存。

**平台图标会自动匹配**：按平台名称或接口地址识别 DeepSeek、Gemini、Claude、Grok、OpenAI、Kimi、智谱、通义、硅基流动、OpenRouter、Ollama、小米、字节、百度、Meta、Mistral、Perplexity 等，
显示各自官方 logo。识别不出来时用**灰底首字母**兜底。

点平台标题左边的图标按钮，会弹出图标面板，可以手动指定；选「自动」则恢复按名称匹配。

> 图标来自 [simple-icons](https://simpleicons.org) 与 [Iconify](https://iconify.design) 的 `logos` / `thesvg` 图标集，
> 全部为各厂商官方 logo，已内联到 `public/icons.js`（25KB），断网也能正常显示。

支持任何 OpenAI 兼容接口：

| 服务商 | 接口地址 |
|---|---|
| DeepSeek | `https://api.deepseek.com/v1` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` |
| Kimi | `https://api.moonshot.cn/v1` |
| 硅基流动 | `https://api.siliconflow.cn/v1` |
| 本地 Ollama | `http://127.0.0.1:11434/v1` |

### 2. 拉取模型列表

平台详情里点 **「从接口获取模型列表」**，程序会调用该平台的 `GET /models`，把可用模型全部拉下来。
如果平台不支持这个接口，也可以点「手动添加模型」自己填 ID。

### 3. 选择当前模型

- **点模型行** → 设为当前使用（行首圆点变实心）
- **点行尾的「文本 / 视觉」标签** → 切换该模型的类型
- 文本模型负责普通题；视觉模型负责图片题，没配视觉模型时图片题会回退到文本模型

选完点「保存配置」。点「测试当前模型」可以立刻验证能不能通。

### 4. 深度思考

在左栏底部「通用设置」里，**默认关闭**。

开启后可以选择推理强度：

| 强度 | 说明 |
|---|---|
| `low` | 快，思维链短 |
| `high` | 均衡（默认） |
| `max` | 最强，最慢也最贵 |

思维链按输出 token 计费。答题这种场景通常不需要开，开着会明显变慢变贵。
如果接口不支持该参数，程序会自动去掉参数重试，不会报错。

同一个页面还能调温度、超时、并发、系统提示词，以及答案自动入库和相似题匹配。

## 三、接到 OCS 上

1. 后台 → 左侧「接入 OCS」→ 点 **复制配置**
2. 打开 OCS 网课助手 → **全局设置 → 题库配置** → 点「新建」
3. 把复制的内容粘进去，保存

配置长这样（程序会自动生成，不用手写）：

```json
[
  {
    "name": "OCS 本地题库+AI",
    "homepage": "http://127.0.0.1:7788",
    "url": "http://127.0.0.1:7788/api/search",
    "method": "post",
    "type": "GM_xmlhttpRequest",
    "contentType": "json",
    "headers": { "Content-Type": "application/json" },
    "data": {
      "v": "2",
      "title": "${title}",
      "options": "${options}",
      "type": "${type}",
      "images": { "handler": "return (env) => env.images" },
      "suggestion_title": "${suggestion_title}",
      "suggestion_options": "${suggestion_options}"
    },
    "handler": "return (res) => res && res.code === 1 ? [res.question, String(res.answer), { source: res.source, matchType: res.matchType, score: res.score, analysis: res.analysis, images: res.imageCount || 0 }] : [res && res.msg ? String(res.msg).slice(0, 80) : undefined, undefined]"
  }
]
```

> 之前贴过旧配置的，请**重新复制一次**再覆盖粘贴 —— 新配置多了图片题字段，见第六节。

**已经有别的题库了怎么办？** OCS 的题库配置是一个数组，把你原来的题库对象**保留在数组里**，用英文逗号接在后面即可，OCS 会按顺序查询。

### 手机 / 别的设备也想用

1. 改 `data/config.json`，把 `"host": "127.0.0.1"` 改成 `"host": "0.0.0.0"`，重启服务
2. 查电脑的局域网 IP（`ipconfig` 里的 IPv4 地址，如 `192.168.1.10`）
3. 把 OCS 配置里的 `127.0.0.1` 全部换成这个 IP

## 四、往题库里加题

后台 → 「题库管理」，四种方式：

**1. 手动加** — 右上角「＋ 添加题目」，填题干、答案、选项即可。
多选答案用 `#` 分隔，如 `A#C`。

**2. 批量导入** — 点「导入题库」，支持粘贴或选文件：

```json
[{"question":"HTTP 默认端口是？","answer":"80","type":"completion"}]
```

```csv
题目,答案,题型
HTTP 默认端口是？,80,completion
```

```
下列哪一项不是操作系统的功能？====C
```

```
下列哪一项不是操作系统的功能？
A. 进程管理
B. 内存管理
C. 文字处理
D. 文件管理
答案：C
```

**3. 让 AI 自己攒** — 「模型配置」里勾上「AI 答出的题自动入库」，之后凡是 AI 答过的题都会自动存下来，下次直接命中。

**4. 导出再编辑** — 「导出」可以下 JSON 或 CSV，用 Excel 批量改完再导入。

### 答案存的是文字，不是 A/B/C

题库里每条都同时记了两样：

```json
{ "answer": "C", "answerText": "文字处理" }
```

返回给 OCS 时用的是 **`answerText`（选项文本）**，因为你看到的题目选项顺序未必和录入时一致 ——
同一道题这次是 `A. 进程管理 B. 文字处理`，下次可能就变成 `A. 文字处理`。
返回字母 `C` 的话就会指错选项，返回文字则永远对得上。

所以：

- **手动加题时填文字最稳**（如 `文字处理`）；填字母 `C` 也可以，系统会按下面的选项自动转成文字
- 多选题用 `#` 连接，如 `提倡民主和科学#提倡白话文`
- 判断题特殊：必须是 `对` / `错`（OCS 判断题不认字母，见第六节）
- 想让 OCS 收到字母而不是文字，把 `data/config.json` 里 `answer.preferText` 改成 `false`

## 五、外部题库源（可选）

如果你已经有别的题库 API，可以在「外部题库源」里加进来，查询顺序是：

```
本地题库 → 外部题库源（可多个，按添加顺序）→ 大模型
```

填法：

| 字段 | 说明 | 例子 |
|---|---|---|
| 接口地址 | 题库的 API 地址 | `https://api.example.com/search` |
| 请求参数模板 | 用占位符拼请求体 | `{"q":"${title}","opts":"${options}"}` |
| 答案字段路径 | 从返回 JSON 里取答案的位置 | `data.answer` |
| 成功判断路径 | 可选，判断是否成功 | `code` + 期望值 `1` |

占位符：`${title}` 题干、`${options}` 选项文本、`${type}` 题型。

填完点「测试」，能弹出命中答案就说明配置对了。

## 六、图片题 / 公式题

OCS 5.1 起，题库配置里如果没有图片相关字段，会提示
**「当前题库配置暂不支持图片、公式等题目处理」**。这是 OCS 在检查配置里有没有
`images`、`suggestion_title`、`suggestion_options` 这几个字段，和题库本身好坏无关。

本服务生成的配置已经包含这些字段，**重新复制一次粘回 OCS 即可消除提示**：

```json
"data": {
  "v": "2",
  "title": "${title}",
  "options": "${options}",
  "type": "${type}",
  "images": { "handler": "return (env) => env.images" },
  "suggestion_title": "${suggestion_title}",
  "suggestion_options": "${suggestion_options}"
}
```

注意 `images` 必须写成这种 handler 形式，**不能写成 `"${images}"`** —— 那样 OCS 会把它转成逗号拼接的字符串，图片就废了。

### 让 AI 真的看懂图片

光有字段不够，还得有能看图的模型。后台「模型配置」里有个**视觉模型**输入框：

- 主模型本身就能看图（如 `gpt-4o`、`qwen-vl-plus`、`glm-4v`）→ 视觉模型留空即可
- 主模型只能读文字（如 `deepseek-chat`）→ 在这里单独填一个视觉模型，图片题会自动切换过去

图片题的处理流程和文字题一样：本地题库 → 外部题库源 → 视觉模型，答案同样会沉淀。

### 图片题怎么入库

图片题按「题干 + 图片指纹」一起建索引，所以：

- 同一张图 + 同样的题干，第二次问就直接命中本地题库
- 换了图但题干一样，不会误命中原先的答案

题库列表里带图的题会显示「N 张图」标记。

### 公式题

如果 OCS 把公式渲染成图片，走的就是上面这套图片流程；如果公式以 LaTeX 文本形式给出，
普通文字模型就能处理，不需要额外配置。

## 七、常见问题

**Q：OCS 里一直提示没答案？**
去后台「在线测试」输入同一道题看链路：
- 本地题库命中 → 说明服务没问题，是 OCS 配置没粘对
- 显示"大模型未配置" → 去「模型配置」填 Key 并测试
- 显示接口报错 → 检查 Key 是否有效、余额是否充足

**Q：答案格式不对（比如多选只回一个字母）？**
「模型配置」里把温度调到 `0`，并在系统提示词里强调多选用 `#` 连接。判断题答案如果 OCS 不认，可以在 `data/config.json` 的 `answer.judgeTrue` / `judgeFalse` 改成 OCS 选项里实际出现的文字（如"正确"/"错误"）。

**Q：选项顺序和题库里不一样，答案会错吗？**
不会。加题时填了选项的话，系统会按选项内容重新映射答案字母。所以**建议加题时把选项也填上**。

**Q：端口 7788 被占用？**
`set PORT=8899 && npm start`，同时把 OCS 配置里的端口一起改掉。

**Q：数据存在哪？怎么备份？**
全部在 `data/` 目录：
- `questions.json` — 题库
- `config.json` — 配置（含 API Key，注意别外传）
- `query.log.jsonl` — 查询日志

直接复制这个目录就是完整备份。

**Q：会不会被学校发现？**
本项目只是把"查题库 / 问 AI"这一步自动化，是否使用、怎么使用由你自己判断并承担后果。请遵守所在学校的相关规定。

## 八、目录结构

```
OCS网课助手/
├── 安装桌面快捷方式.bat   # 装一次，之后从桌面双击启动

├── src/
│   ├── config.js       # 配置读写

│   ├── matcher.js      # 题干归一化、相似度、答案格式化

```

```bash
node tests/run-all.js
```

**不会动你的真实题库和 API Key**。共三个测试文件：

| 文件 | 覆盖内容 |
