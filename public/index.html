3 步接入 OCS 网课助手
复制下面的题库配置

点击「复制配置」，内容是 OCS 要求的 JSON 数组格式，已包含请求地址和解析规则。

打开 OCS → 全局设置 → 题库配置 → 新建

把内容粘贴进去，保存。注意 OCS 的题库配置是一个整体数组，若已有其他题库，用逗号拼接在数组里。

回到本页「在线测试」验证

测试能出答案后，OCS 里答一次题看控制台日志即可。本服务需保持运行（双击「启动服务.bat」）。

图片题 / 公式题
上面的配置已经包含 OCS 5.1+ 的图片题字段（images、suggestion_title、suggestion_options、v）， 粘贴后 OCS 里那条「暂不支持图片题优化」的提示会自动消失。
真正让 AI 看懂图片还需要一个支持视觉的模型：在「模型配置」里填「视觉模型」，或直接让主模型用视觉版本。
公式题：如果 OCS 把公式渲染成图片，走的是同一套流程；如果是 LaTeX 文本，普通模型即可处理。
